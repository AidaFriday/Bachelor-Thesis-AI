🔹 1. FaceNet (2015, Google)

Backbone: CNN (e.g., Inception-ResNet).

Key idea: Learns a 128-D embedding of faces using a triplet loss function.

Ensures that:

Distance(anchor, positive) < Distance(anchor, negative) by a margin.

Strengths:

First to show high-accuracy embeddings could replace classifiers.

Open-source implementations widely available.

Limitations:

Requires careful triplet mining (choosing anchor/positive/negative).

Older backbone compared to modern models.

📌 Use in BA: A good baseline model to show how newer approaches outperform earlier deep learning embeddings.

🔹 2. ArcFace (2019)

Backbone: CNN (ResNet, MobileFaceNet, etc.).

Key idea: Uses Additive Angular Margin Loss (ArcFace loss).

Makes decision boundaries angular, improving class separation.

Embeddings lie on a hypersphere → more discriminative and robust.

Strengths:

Consistently state-of-the-art performance on benchmarks (LFW, IJB-C, MegaFace).

Simple, stable, easy to train.

Limitations:

Requires large-scale, clean training data.

📌 Use in BA: Represents the modern standard CNN-based embedding approach.

🔹 3. MagFace (2021)

Backbone: CNN (ResNet variants).

Key idea: Introduces magnitude-aware face embeddings.

Embedding norm encodes face image quality (pose, blur, occlusion).

Loss function encourages high-quality images → larger embedding norms.

Strengths:

Provides both identity discrimination and face quality assessment.

Robust under unconstrained conditions (blur, occlusion, low-res).

Limitations:

Slightly more complex training.

Still requires significant compute.

📌 Use in BA: Represents the latest generation of face embeddings, tackling not only recognition but also quality estimation — useful in real-time scenarios where input quality varies.
